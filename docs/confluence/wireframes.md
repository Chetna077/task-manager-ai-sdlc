# Wireframes

## Main screen

```
+--------------------------------------------------------------+
| Task Manager                                                 |
+--------------------------------------------------------------+
| [ Search title...      ] [Status: All v] [Priority: All v]   |
| Sort by: [Due date v] [Asc v]                                |
+--------------------------------------------------------------+
| + Add task                                                    |
| [ Title            ] [ Due date ] [ Priority v] [ Add ]      |
+--------------------------------------------------------------+
| [ ] To Do    "Write report"        High    Due 2026-09-25    |
|              [Edit] [Start] [Delete]                         |
|--------------------------------------------------------------|
| [~] In Prog. "Fix login bug"        Medium  Due 2026-09-23 ⚠ |
|              [Edit] [Done] [Delete]                           |
|--------------------------------------------------------------|
| [x] Done     "Update README"        Low     Due —             |
|              [Edit] [Reopen] [Delete]                         |
+--------------------------------------------------------------+
```

`⚠` = overdue flag (FR-8): due date in the past and status ≠ Done.
