# Jira story writing

1. One epic per feature area; stories as 'As a <user>, I want <goal>, so that <benefit>'.
2. Acceptance criteria in Given/When/Then.
3. Add Priority (High/Medium/Low) and Effort (S/M/L).
4. Add Development, Testing and Documentation sub-tasks per story.
5. Never create or change Jira items without human approval.
