# Gherkin and Playwright testing

1. One .feature file per story: Feature, Scenario, Given/When/Then.
2. Cover happy path, validation errors and edge cases.
3. Playwright specs mirror the scenarios; use stable selectors.
4. Output a test execution report with pass/fail per scenario.
